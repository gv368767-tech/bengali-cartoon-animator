# APK বানানো ও ফোনে ইনস্টল (ধাপে ধাপে, ফ্রি)

## পদ্ধতি ক — GitHub দিয়ে APK (কম্পিউটারে কিছু ইনস্টল লাগে না, ব্রাউজারেই হয়)
1. github.com-এ বিনামূল্যে অ্যাকাউন্ট খুলুন।
2. **New repository** → নাম `bengali-cartoon-animator` → **Public** → Create।
3. রেপোতে **uploading an existing file** লিংকে চাপুন। এই জিপ খুলে ভেতরের **সব ফাইল ও ফোল্ডার** (লুকানো `.github` ফোল্ডারসহ) টেনে ছেড়ে দিন → Commit।
   - `.github` ফোল্ডার না দেখা গেলে ফাইল ম্যানেজারে "hidden files দেখান" চালু করুন। এটি ছাড়া APK বিল্ড হবে না।
4. রেপোর **Actions** ট্যাবে যান → "Build Android APK" → **Run workflow**।
5. ১৫-২৫ মিনিট অপেক্ষা করুন। সবুজ ✔ হলে সেই রানে চাপুন → নিচে **Artifacts** → `BengaliCartoonAnimator-apk` নামান (জিপ)।
6. জিপ খুলে `.apk` ফাইলটি ফোনে পাঠান (Drive/ইউএসবি/টেলিগ্রাম)।

## ফোনে ইনস্টল
1. ফোনে APK ফাইলটি ফাইল ম্যানেজারে খুলুন।
2. "অজানা উৎস থেকে ইনস্টল" অনুমতি চাইলে **Settings → অনুমতি দিন** (শুধু ওই অ্যাপের জন্য)।
3. **ইনস্টল** চাপুন। Play Protect সতর্কতা এলে "তবুও ইনস্টল" বাছুন (কারণ অ্যাপটি Play Store-এর নয়, আপনার নিজের বানানো)।

## পদ্ধতি খ — দ্রুত টেস্ট (কম্পিউটার + Expo Go)
```bash
npm install
npx expo start
```
ফোনে Play Store থেকে **Expo Go** ইনস্টল করে QR স্ক্যান করুন (একই Wi-Fi)।

## বিল্ড ফেল করলে
Actions-এর লাল রানে চেপে যে ধাপটি লাল, তার লগের শেষ ২০ লাইন আমাকে পাঠান, আমি ঠিক করে দেব।

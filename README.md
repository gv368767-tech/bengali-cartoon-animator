# Bengali Cartoon Studio
আঁকতে না জানলেও ৫০টি তৈরি কার্টুন (মানুষ, প্রাণী, পাখি, প্রকৃতি, বস্তু, ৮টি ব্যাকগ্রাউন্ড) দিয়ে অ্যানিমেটেড ভিডিও বানানোর অ্যান্ড্রয়েড অ্যাপ। সম্পূর্ণ বিনামূল্যে, কোনো পেইড API নেই।

## APK পাওয়া ও ইনস্টল (ফোনেই)
1. GitHub-এ push হলে Actions নিজে APK বানায় (~১৫ মিনিট)।
2. রেপোর **Releases** পেজে যান → সর্বশেষ রিলিজ → `.apk` ফাইলে ট্যাপ করে ডাউনলোড।
3. ফোনে ফাইলটি খুলুন → "Unknown sources / এই উৎস থেকে ইনস্টল" অনুমতি দিন → Install।
4. বাংলা কথা শুনতে: Settings → ভাষা → টেক্সট-টু-স্পিচ → Google ইঞ্জিনে বাংলা ভয়েস নামান।

## ফোল্ডার
- `src/art` — ভেক্টর অ্যাসেট; `src/lib` — দৃশ্য/প্লেব্যাক/সেভ/এক্সপোর্ট; `src/screens` — স্ক্রিন
- `modules/studio-export` — Kotlin: MediaCodec দিয়ে MP4 (720p/1080p) ও বাংলা TTS অডিও
- `assets/music` — নিজস্ব তৈরি মিউজিক; `legacy/drawing-animator` — আগের আঁকার অ্যাপের কোড (অক্ষত)
- `tools/` — PNG তৈরির স্ক্রিপ্ট; `tests/scene.test.ts` — `npm test`
